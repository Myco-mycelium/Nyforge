# sdk/

Reserved for a future third-party component authoring SDK — a way to add a
new entry to the component vocabulary (`docs/reference/nui-schema/NUI-SCHEMA.md`
§4) without editing `Nyforge.Core` directly. Not started; v0.1's component
vocabulary is fixed and hand-maintained in
`source/Nyforge.Core/Nui/ComponentContracts.cs`. See `engineering/ROADMAP.md`.
