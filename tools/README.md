# tools/

No build tooling or CLI utilities exist yet. `dotnet build`/`dotnet test`
against `Nyforge.sln` covers everything v0.1 needs. This directory is here
to match Nythera's repository layout convention and reserve the place a
future NUI schema validator, `.nstudio` migrator, or CLI exporter would go
(see `engineering/ROADMAP.md`).
